## PARHAF dataset

The PARHAF corpus is released by the
[Health Data Hub](https://www.health-data-hub.fr/) on HuggingFace
under its own terms. Read and follow the dataset license before
using it in a downstream project.

## Citing the package

If you use `parhaf-clinbench` in academic work, cite it with the
following BibTeX entry. Replace `<VERSION>` and `<COMMIT>` with the
values from the run you used.

```bibtex
@software{parhaf_clinbench,
  author  = {Mechouek, Lounes},
  title   = {parhaf-clinbench: A reproducible benchmark for clinical information extraction with language models on PARHAF},
  year    = {2026},
  url     = {https://github.com/lounesmechouek/parhaf-clinbench},
  version = {<VERSION>},
  note    = {Commit <COMMIT>}
}
```
